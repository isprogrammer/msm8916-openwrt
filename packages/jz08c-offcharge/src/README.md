# Renderer

jz08c-power-ui.c renders the 128x128 RGB565 charge and poweroff screens to fb0.
It checks framebuffer geometry and stride, draws the selected packaged frame,
adds the battery indicator from the PM8916 BMS capacity, and polls charger and
power-key state.

The package Makefile builds this source for the target. Raw RGB565 frames are
reproducibly generated by ../tools/generate_assets.py.
